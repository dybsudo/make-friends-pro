## 核心功能

- **遇见系统**：提供同频用户推荐、推荐换一批、用户主页查看等功能，帮助用户从兴趣和真实表达出发发现更值得认识的人。
- **信件社交**：支持随机收信、匿名写信、图片信件、标签匹配、回信及信箱管理，让陌生人社交更自然、更有仪式感。
- **内容广场**：支持图文发布、标签分类、内容搜索、推荐动态和关注动态，轻松构建内容丰富、持续活跃的社区氛围。
- **内容互动**：内置收藏、分享、评论、回复、共鸣、关注与举报等完整能力，让每一条优质内容都能转化为真实互动。
- **实时聊天**：支持文字、图片、语音、动态礼物、历史消息、消息未读数、送达状态和已读状态，带来接近成熟社交 App 的沟通体验。
- **稳定通信**：支持实时消息推送、断线自动重连和发送失败暂存，有效应对网络波动，让聊天过程更加稳定可靠。
- **社交关系**：提供关注、粉丝、用户主页、个人资料、隐私设置、消息通知、用户拉黑及互动提醒等完整能力。
- **会员与资产**：内置 VIP、钻石、签到任务、充值订单、礼物商城、魅力等级及礼物图鉴，轻松形成商业化闭环。
- **安全运营**：集成文字审核、媒体安全、内容举报、用户管理、礼物配置、订单管理及功能完善的运营后台。
